Ayuda: Traslados entre bodegas

Este formulario permite registrar traslados de productos, consultar su avance, actualizar solicitudes activas y revisar el detalle de cada traslado.

1. Crear un nuevo traslado

  1. Presione Nuevo. Se habilitarán los campos para ingresar una solicitud.
  2. Escriba el código del traslado (hasta 30 caracteres), seleccione la Bodega Origen y una Bodega Destino diferente. Al cambiar el origen, el sistema actualiza los productos disponibles y excluye esa bodega de los destinos.
  3. Seleccione el Tipo de Transporte y luego una placa disponible para ese tipo. Puede elegir un conductor de la lista de conductores disponibles; la solicitud inicial también puede guardarse sin conductor asignado.
  4. Seleccione un producto de la bodega de origen, indique una cantidad mayor que cero y presione Agregar. Repita para incluir otros productos. Si agrega de nuevo un producto ya incluido, su cantidad se acumula.
  5. Para retirar un producto, selecciónelo en la tabla de detalle y presione Eliminar. Si cambia la bodega de origen después de agregar productos, confirme el aviso para quitar el detalle anterior.
  6. Ingrese las observaciones si son necesarias (máximo 500 caracteres) y presione Guardar. La solicitud se crea con estado SOLICITADO y debe incluir al menos un producto.

Para pasar el traslado a EN_TRANSITO o RECIBIDO, se debe asignar un tipo y un transporte disponibles. La bodega de origen y la de destino no pueden ser iguales.

2. Modificar un traslado

  1. Seleccione el traslado en la tabla inferior y presione Modificar. Los traslados RECIBIDO o CANCELADO son históricos y no se pueden modificar.
  2. Si el estado es SOLICITADO, puede actualizar las bodegas, el transporte, el conductor, los productos y las observaciones. Para cambiar el estado, las opciones disponibles son EN_TRANSITO y CANCELADO.
  3. Si el estado es EN_TRANSITO, puede actualizar las observaciones y cambiar el estado a RECIBIDO o CANCELADO. Los datos del transporte y los productos quedan bloqueados.
  4. Presione Guardar para aplicar los cambios o Cancelar para descartar la edición.

3. Buscar traslados

  1. Ingrese, si lo desea, parte del Código de Traslado.
  2. Para filtrar por fecha, marque la casilla del selector de fecha y elija la fecha de solicitud.
  3. Elija un Estado de Traslado o deje Todos para no limitar por estado. Los filtros se pueden combinar; un campo vacío no se aplica.
  4. Presione Buscar. La tabla mostrará los registros que coincidan con los criterios ingresados.

4. Consultar el detalle

Seleccione un traslado en la tabla y presione Ver detalle. Se abrirá la ventana Detalle de Traslado con los datos generales, productos y totales. Si no hay una fila seleccionada, el formulario solicitará que seleccione un traslado.

5. Navegar por los registros

Use los botones de navegación para mostrar el primer registro (Inicio), el anterior, el siguiente o el último (Fin) de la lista cargada. La selección actual se refleja en los campos del formulario.

6. Imprimir el reporte

Presione Imprimir para abrir el reporte de traslados registrados. Desde la ventana del reporte puede revisar la presentación y utilizar las opciones de impresión disponibles.

7. Cancelar o salir de la edición

Presione Cancelar mientras crea o modifica un traslado para descartar los cambios no guardados y regresar a la consulta. Para cerrar el formulario, use el control de cierre de la ventana.
