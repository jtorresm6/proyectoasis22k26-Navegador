Proceso

Ayudas - Movimientos Bancarios


Descripción

El proceso de Movimientos Bancarios permite registrar movimientos conciderando el concepto selecionado y orientado hacia un beneficiario (empleado, proveedor o cliente); permitiendo seleccionar cuentas bancarias tanto del beneficiario como de la empresa.



Pantalla principal

Al seleccionar esta opción se despliega una ventana en la cual podemos ver los movimientos bancarios ya registrados dentro de la empresa.




Opcion de Movimientos Bancarios

Al seleccionar el boton de "Movimientos Bancarios" se despliega un menu el cual contiene cuatro botones que serán descritos en breves.




1. Cuando todos los campos esten completos, sin errores lógicas, se permitirá registrar el movimiento al sistema.

2. Pemite limpiar todos los campos del formulario, dejandolo en blanco.

3. Permite observar la guía del usuario para este formulario.

4. Permite volver a la lista de movimientos bancarios.

Concepto Bancario

Si presionamos el botón que está junto al texto de concepto, nos desplegará una ventana en la cual contendrá todos los conceptos bancarios que están disponibles para el sistema. También contamos con una ventana en la cual podremos buscar el nombre del concepto para poder facilitar la búsqueda y al terminar de encontrar el concepto podemos darle clic a ese nombre del concepto para poder registrarlo en los campos requeridos.




Forma de Pago

Luego de seleccionar el concepto que nosotros hayamos deseado, tenemos que seleccionar la forma de pago a la cual será transferido el dinero, por lo cual debemos de seleccionar en la lista que tendríamos a la par del texto de método de pago.




Tipo de Transacción

Luego de seleccionar la forma de pago debemos de seleccionar un tipo de transacción el cual debe de coincidir con la lógica que se estará llevando para el método de pago.




Fechas de Registro y Aplicación

En este apartado tenemos que seleccionar tanto la fecha de registro como de aplicación. Estas fechas no deben de ser mayores a la del día actual ni la de aplicación debe de ser menor a la de registro.




Beneficiario

Justo en la parte del texto de beneficiarios se encuentra un botón el cual desplegará una ventana que contendrá una lista de todos los beneficiarios que estén registrados en el sistema. Cabe aclarar que esto dependerá de cuál concepto se haya seleccionado. Si por ejemplo seleccionamos como este caso de las imágenes un concepto el cual involucra a un cliente, los beneficiarios involucrados solamente serán clientes. De igual manera con proveedores y clientes. Podemos también hacer una búsqueda de los nombres de los empleados, proveedores o cliente que hayamos seleccionado. Podemos darle clic al nombre del beneficiario para poder registrarlo en los campos requeridos.




Cuentas Bancarias

Dependiendo de qué empleado, cliente o proveedor hemos seleccionado, la lista de cuentas bancarias de ese beneficiario será relacionada a las cuentas que tiene esta persona, por lo que podremos decidir en qué cuenta será depositado o extraído ese dinero. También debemos seleccionar una cuenta de la empresa en la cual nos estará mencionando cuánto monto es el que tiene disponible para poder hacer el movimiento y de este modo asegurarse de que tenga las cantidades suficientes para el movimiento requerido.




Registrar Movimiento Bancario

Luego de tener todos los campos seleccionados y ya toda la lógica incorporada para el movimiento podremos registrar el movimiento con el siguiente botón. Esto lo que hará será preguntar de primeras si tenemos todos los datos necesarios y requeridos para poder realizar el movimiento. De ser así, accede a realizar el movimiento y podremos regresar a la lista de movimientos para ver que ya está registrado dentro del sistema.




De igual manera se descontará o contará la cantidad de dinero de las cuentas respectivas e involucradas.
