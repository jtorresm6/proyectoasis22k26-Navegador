Mantenimiento de cuentas bancarias

Esta ventana del módulo de Bancos permite ingresar, consultar, modificar y eliminar cuentas bancarias mediante la barra del Navegador. Los datos guardados se muestran en la tabla desplegable. Los botones inferiores de Reporte y Ayuda abren el listado imprimible de cuentas y este manual, respectivamente.

Las acciones disponibles dependen de los permisos del usuario. Los campos se generan a partir de la estructura de cuentas bancarias de la base de datos instalada; utiliza los nombres que aparecen en tu formulario.

1. Ingresar una cuenta bancaria

  1. Presiona Ingresar en la barra del Navegador. Se desplegarán la tabla de cuentas y el panel para capturar un registro nuevo.
  2. Completa los campos habilitados. Revisa cuidadosamente el número de cuenta y los demás datos que solicite el formulario. Conserva los ceros iniciales que formen parte del número de cuenta.
  3. En las listas de datos relacionados, selecciona un registro existente del catálogo correspondiente. Si no aparece la opción necesaria, primero debe registrarse en su mantenimiento.
  4. Los campos que muestran (automático) los asigna el sistema: no debes escribir en ellos.
  5. Presiona Guardar, revisa la confirmación y acepta para registrar la cuenta. El mensaje Registro guardado correctamente confirma la operación y la tabla se actualiza.

Si deseas abandonar la captura antes de guardar, presiona Cancelar. Si aparece una validación, corrige el dato indicado y vuelve a guardar.

2. Consultar y buscar una cuenta

  1. Presiona Consultar. El sistema carga la tabla y abre la ventana del componente Consultas.
  2. Selecciona el Campo por el que quieres buscar, elige un Operador, escribe el Valor y presiona Buscar cuando el botón se habilite.
  3. Selecciona el registro en Consultas. Al regresar, la tabla del Navegador mostrará la cuenta elegida, filtrada por su identificador.
  4. Haz clic sobre la fila para dejarla seleccionada si deseas modificarla o eliminarla.
  5. Para volver al listado completo, presiona Refrescar.

Si cierras Consultas sin seleccionar un registro, queda disponible la tabla completa que se cargó al iniciar la consulta.

3. Modificar una cuenta bancaria

  1. Localiza la cuenta mediante Consultar o despliega el listado con Refrescar.
  2. Selecciona su fila y presiona Modificar.
  3. El panel se abrirá con los datos actuales. Cambia únicamente los campos necesarios; el identificador o llave primaria permanece bloqueado durante la modificación.
  4. Presiona Guardar y confirma la operación. Verifica el mensaje de éxito y los datos actualizados en la tabla.

Para descartar cambios que todavía no se han guardado, presiona Cancelar.

4. Eliminar una cuenta bancaria

  1. Consulta la cuenta y selecciona la fila correcta en la tabla.
  2. Verifica su identificador y número de cuenta antes de presionar Eliminar.
  3. Lee la confirmación. Selecciona Sí para eliminar o No para conservar el registro.
  4. Cuando aparezca Registro eliminado correctamente, la tabla se actualizará.

Una cuenta relacionada con otros registros puede tener restricciones que impidan su eliminación. Si el sistema rechaza la operación, revisa el mensaje mostrado. Cancelar no recupera una cuenta que ya fue eliminada.

5. Guardar y cancelar

Guardar: se utiliza después de Ingresar o Modificar. Valida los datos y solicita la confirmación correspondiente. Si hay un error, el panel permanece abierto para corregirlo. Si no hay un registro en edición, el sistema te pedirá abrir uno primero.

Cancelar: cierra el panel de captura o modificación y descarta lo que aún no se haya guardado. No deshace operaciones ya confirmadas.

6. Recorrer la tabla y refrescar

Inicio, Anterior, Siguiente y Fin: permiten recorrer las filas del listado mostrado. También puedes seleccionar una cuenta directamente con un clic en la tabla.

Refrescar: vuelve a consultar las cuentas guardadas y muestra el listado completo. También cierra el panel de edición, por lo que debes guardar tus cambios antes de usarlo si deseas conservarlos.

La tabla es de consulta: para cambiar valores utiliza Modificar. Las columnas corresponden a los campos disponibles en la base de datos instalada.

7. Generar, imprimir y exportar el reporte

  1. Guarda los cambios de la cuenta antes de generar el reporte.
  2. Presiona el botón Reporte ubicado en la parte inferior de Cuenta Bancaria.
  3. Se abrirá Reporte de cuentas bancarias con el listado completo de cuentas guardadas, sus columnas, la fecha de generación y la cantidad de registros. La selección o búsqueda del Navegador no limita este listado.
  4. Utiliza los controles del visor para cambiar de página, ajustar el zoom o buscar texto dentro del reporte.
  5. Para obtener una copia, usa Imprimir o el menú Exportar del visor y selecciona un formato disponible, como PDF o Excel.
  6. Cierra el visor para regresar al mantenimiento. Si cambian los datos, cierra y abre de nuevo el reporte para consultar una versión actualizada.

Si no existen cuentas, el visor indicará que no hay cuentas bancarias registradas. El botón Imprimir de la barra del Navegador abre el componente general Reporteador y sus reportes configurados; para este listado específico utiliza el botón inferior de Reporte.

8. Ayuda y salir

Ayuda inferior: abre este manual de Cuenta Bancaria en el navegador web predeterminado. Ayuda de la barra del Navegador: abre la documentación general de ese componente.

Salir en la barra del Navegador: cierra el panel de edición y contrae la tabla, dejando visible la barra. Para cerrar Cuenta Bancaria, utiliza el control de cierre de la ventana. Guarda primero cualquier cambio que desees conservar.

9. Mensajes frecuentes

Seleccione un registro: despliega la tabla y haz clic en una fila antes de modificar o eliminar.

Datos incompletos, identificador duplicado o referencia inexistente: revisa los campos indicados y selecciona valores válidos de los catálogos relacionados.

Error al cargar la tabla o el reporte: verifica que la conexión a la base de datos esté disponible y solicita al administrador revisar la configuración si el problema continúa.
