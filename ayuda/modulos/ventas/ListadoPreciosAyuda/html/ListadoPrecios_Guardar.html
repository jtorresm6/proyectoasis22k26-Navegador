Guía de Listado de precios | Consultar y filtrar el listado | Modificar precios y descuentos | Guardar los cambios | Botones de Listado de precios | Mensajes frecuentes de Listado de precios

  1. Revise la vista previa en la tabla y compruebe que ningún precio quede negativo.
  2. Presione Guardar. El sistema valida el valor, el alcance y las filas seleccionadas.
  3. Aparece un mensaje de confirmación con la cantidad de registros, el alcance elegido y el efecto del cambio. Presione Sí solo si está de acuerdo.
  4. Lea el mensaje del resultado. Si se guardó, el listado se recarga con los datos actualizados.

Qué se actualiza

Campo / acciónUso
Descuento (%)El porcentaje del tipo de cliente. Se actualiza una vez por cada tipo de cliente afectado.
Aumento por porcentaje (%) o por baseEl precio de venta del producto. Se actualiza una vez por cada producto afectado.
Varios cambios a la vezSe guardan juntos: si ocurre un error, no se guarda ninguno.

Cancelar

Presione Cancelar y confirme para limpiar los filtros y regresar la modificación a sus valores iniciales. Los cambios que ya guardó no se deshacen.

No mezcle tipos de modificación en una misma operación. Para aplicar un descuento y un aumento, guarde uno primero y luego realice el otro.
