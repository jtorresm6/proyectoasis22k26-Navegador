1. Tipo de modificación

Campo / acciónUso
Descuento (%)Cambia el porcentaje de descuento del tipo de cliente. El nuevo porcentaje se aplica a todos los productos de ese tipo de cliente.
Aumento por porcentaje (%)Aumenta el precio base del producto en el porcentaje indicado. El cambio afecta a todos los tipos de cliente del producto.
Aumento por baseSuma un importe fijo al precio base del producto. El cambio afecta a todos los tipos de cliente del producto.

2. Valor

Para Descuento (%) y Aumento por porcentaje (%) use el campo numérico, de 0 a 100 con dos decimales. Para Aumento por base escriba el importe en la caja de texto de abajo; no puede ser negativo. El sistema habilita solo el campo que corresponde al tipo elegido.

3. Alcance de modificación

Campo / acciónUso
Producto InvididualModifica exactamente una fila. Haga clic en la fila que desea cambiar.
Productos seleccionadosModifica las filas que seleccione. Use Ctrl + clic para elegir filas sueltas o Shift + clic para un rango.
Todos los resultado (segun filtros)Modifica todas las filas que muestra la tabla con los filtros actuales.

Pasos

  1. Filtre el listado hasta ver los productos que desea cambiar.
  2. Elija el tipo de modificación y escriba el valor.
  3. Elija el alcance y, si no es “Todos los resultado”, seleccione las filas en la tabla.
  4. Revise en la tabla la vista previa de Precio base, Descuento (%) y Precio final.
  5. Presione Guardar para registrar el cambio. Mientras no guarde, la base de datos no se modifica.

Ejemplo: con precio base de Q80.00 y descuento de 10 %, un aumento por porcentaje de 5 % da un precio base de Q84.00 y un precio final de Q75.60. Un aumento por base de Q3.00 da un precio base de Q83.00 y un precio final de Q74.70.

Atención: el descuento pertenece al tipo de cliente, no a cada producto. Aunque seleccione una sola fila, el nuevo porcentaje se guarda para todos los productos de ese tipo de cliente.
