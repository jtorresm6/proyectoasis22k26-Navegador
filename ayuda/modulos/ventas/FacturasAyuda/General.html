Embutidos de Calidad, S.A. · Ventas y cuentas por cobrar · Aplicación 7007.

Esta guía explica cómo preparar, revisar y guardar una factura manual o procedente de una cotización o pedido, generar su PDF y abrir la vista previa de impresión.

Antes de comenzar

  • Inicie sesión con un usuario activo.
  • El cliente debe estar activo y tener una lista de precios vigente para la venta manual.
  • Debe haber existencias disponibles y un período abierto para la moneda.

El establecimiento es Embutidos de Calidad, S.A., NIT 25103. Su dirección es 3a. Avenida 9-00 zona 2 Interior Finca El Zapote.

Se generan facturas locales con UUID propio. No se realiza certificación FEL.
