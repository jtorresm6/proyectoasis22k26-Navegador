Descripción general

Muestra el historial de acciones del sistema en una tabla de solo lectura. Abre Bitácora desde el MDI.

¿Cómo consultar el historial?

  1. Escribe un usuario, acción, tabla, registro, detalle, dirección IP o fecha en la búsqueda.
  2. Pulsa Buscar o Enter.
  3. Revisa las filas del resultado. Borra el texto y vuelve a buscar para consultar el historial completo.
  4. Utiliza el botón de reportes del encabezado para abrir el reporte del historial completo, si tienes permiso de impresión.

Acciones disponibles

AcciónQué hace
Buscar / EnterAplica el texto de búsqueda.
ReporteConsulta el historial completo en el reporte; requiere permiso de impresión.

Avisos y soluciones

Si el reporte no abre, revisa el mensaje, el permiso de impresión y la disponibilidad del archivo de reporte. Esta pantalla permite consultar el historial, sin editar sus registros.
