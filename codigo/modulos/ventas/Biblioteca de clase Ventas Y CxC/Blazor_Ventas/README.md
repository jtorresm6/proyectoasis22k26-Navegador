# Listado de precios — Blazor

Abra `VentasListadoPrecios.sln`, ubicada directamente en esta carpeta, y seleccione el perfil **http**.

La página del listado utiliza `http://localhost:5000/ventas-listado-precios`, la misma dirección del botón Listado de precios del MDI. Inicie esta aplicación antes de utilizar dicho botón.

Estructura:

    Blazor/
      VentasListadoPrecios.sln
      VentasListadoPrecios/
        VentasListadoPrecios.csproj
        Pages/
        wwwroot/

Se conserva el proyecto .NET 7 y el diseño del ZIP proporcionado. Se excluyeron carpetas temporales de Visual Studio y resultados de compilación (.vs, bin y obj).
